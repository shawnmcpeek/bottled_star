# Bottled Star

A fusion drop-and-merge physics game. Inject hydrogen into a circular chamber, fuse elements up the stellar ladder, and keep the pile from breaching containment.

**Studio:** Daddoo Dev  
**Stack:** Flutter · Flame · forge2d

## Run

```bash
flutter run -d linux    # desktop playtest
flutter run -d android
flutter run -d ios
```

## Controls

- **Touch / mouse:** drag to aim, hold to charge, release to fire
- **Keyboard:** A/D or arrows to rotate, Space to charge/fire, R/Enter to restart after a loss
