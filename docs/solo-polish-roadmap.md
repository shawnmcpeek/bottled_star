# Bottled Star — achievable polish (solo / indie / AI conductor)

Improvements that raise “premium feel” without a studio art/audio budget. Ordered by leverage.

## 1. Juice the core loop

- Stronger feedback on merges: particles, brief punch, layered pluck clarity
- Rim pressure: visual/audio escalation as the chamber fills toward crack
- Supernova: flash, shake curve, settle — readable as the run’s climax
- Kilonova: distinct beat from supernova (color, SFX sting, score pop)
- Short slow-mo or hitch only on rare big moments (first Fe, first blast, first kilo)

## 2. First-run teaching by play

- First ~60s force one clean win: aim → charge → inject → fuse
- Delay jargon (kilonova, remnant, ladder tiers) until after first success
- One guided beat into Classic before Mode Select feels like a menu of unknowns
- Soft tooltips only when the player is stuck, not a wall of text up front

## 3. One hero moment

- Script or heavily juice **first iron**, **first supernova**, and **first kilonova**
- Those three should be trailer-worthy from existing art + better staging
- Ending card copy and timing should land like a beat, not a dismissible dialog

## 4. Mode clarity at the door

- Classic / Collapse / Challenge: one sentence + one iconic still each on Mode Select
- Collapse scoring (kilonovas first, shots second) stated once, clearly
- Challenge packs read as a short campaign, not a locked shop shelf

## 5. Challenge as the campaign

- Tighten pack difficulty curves (teach → twist → exam)
- Stronger level names and one-line flavor that match the puzzle
- Clear win/fail language; satisfying clear screens
- Visible pack progress on home / level select (“Pack 2 · 4/10”)

## 6. UI hierarchy

- Quiet the HUD: emphasize the number that matters *now*
- Collapse: kilonovas/shots primary; Classic: score/peak primary
- Reduce competing gold text; use space and contrast instead of more labels
- Pause / leave / quiet-end affordances stay discoverable without clutter

## 7. Audio as identity

- Keep mode-tied pluck languages; make merge → climax layers clearer
- Use silence right before supernova / kilonova
- Verify volume defaults and ducking so SFX never fight the loop
- One consistent “brand sting” for major unlocks / clears

## 8. Progression breadcrumbs

- Home screen shows next hook: peak tier, pack progress, or “try Collapse”
- Achievements visible enough to chase without a second app
- After a personal best or Challenge clear, surface “what’s next” once

## 9. Presentation outside the binary

- Keep marketing screenshots captioned and feature-focused
- Short trailer (15–25s) of juiced captures: inject → fuse → iron → blast
- Confident What’s New notes on each ship
- Store title/description stay keyword-honest (fusion game) without spam

## 10. Trust and finish

- Save/resume never surprises; abandon confirms stay clear
- Restore purchases reliable on both stores
- Rate / share only after positive moments (already started)
- Exit confirm on home (done); keep accidental-loss paths covered
- Localization later if markets demand it; English polish first

## Suggested build order

1. Juice supernova + kilonova + merge punch  
2. Rewrite first-run into a forced first win  
3. Mode Select clarity + Challenge progress chrome  
4. Hero-moment staging for Fe / supernova / kilonova  
5. Trailer + refresh store stills from juiced builds  

## Notes for AI-conductor workflow

- Prefer small vertical slices: one moment juiced end-to-end per PR  
- Capture before/after clips for trailer and store  
- Re-run Challenge sims / level tests whenever physics feedback timing changes  
- Ship often; each release should have one feel upgrade players notice in 30 seconds
